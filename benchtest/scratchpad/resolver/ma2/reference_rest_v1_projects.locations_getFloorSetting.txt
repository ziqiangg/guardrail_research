Gets details of a single floor setting of a project
HTTP request
GET https://modelarmor.googleapis.com/v1/{name=projects/*/locations/*/floorSetting}
The URL uses gRPC Transcoding syntax.
Path parameters
| Parameters
| name
|
string
Required. The name of the floor setting to get, example projects/123/floorsetting.
Request body
The request body must be empty.
Response body
If successful, the response body contains an instance of FloorSetting.
Authorization scopes
Requires the following OAuth scope:
https://www.googleapis.com/auth/cloud-platform
For more information, see the Authentication Overview.
IAM Permissions
Requires the following IAM permission on the name resource:
modelarmor.floorSettings.get
For more information, see the IAM documentation.
