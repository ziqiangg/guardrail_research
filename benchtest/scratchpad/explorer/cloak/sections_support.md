# Get Support

## Cloak Support Assistant

Our **Support Assistant** is the fastest way to get help with Cloak. It can:

- Guide you through features and usage steps (tabular anonymisation, free-text anonymisation, decryption, templates)
- Help you navigate the Web UI, APIs, and Python packages
- Troubleshoot common issues with uploads, transformations, entity detection, and API integration
- Advise on how to improve detection quality (e.g. custom entities, inclusion lists, confidence levels)
- Help with registration, onboarding, and access modality selection
- Answer FAQs about data security, classification support, and pricing

We strongly recommend trying the assistant first for the fastest resolution.

[Launch Support Assistant](https://go.gov.sg/cloak-support-assistant)

---

## Raise a Support Ticket

If the Support Assistant is unable to resolve your issue, raise a ticket with our team through the customer portal. The assistant can help you prepare a summary to include in your ticket.

[Raise a Ticket](https://go.gov.sg/cloak-support)
