# Free-text Decryption Usage Guide

!> The Web UI currently supports decrypting **one value at a time** (paste into the text field). If you need to decrypt multiple values or a file of encrypted data, use the [Free-Text Decryption API](https://docs.developer.tech.gov.sg/docs/cloak-api-guide/sections/helper-scripts/secure-internet-api-decryption-freetext) which supports looping through rows in a CSV.

Get started by clicking **Decryption** in the sidebar.

![Sidebar button](_resources/tabular-decryption-9.png ':size=300x')

*Click Decryption in the sidebar to access the decryption options.*

Click **Decrypt Free Text Data**.

![Decryption options](_resources/tabular-decryption-10.png)

*Choose between Decrypt Free Text Data or Decrypt Tabular Data.*

## Step 1: Input your encrypted data

Input your encrypted value into the left text field.

![Input](_resources/free-text-decryption-4.png)

*Input of encrypted value*

## Step 2: Select your secret

This step allows you to choose which secret to use when decrypting your dataset.

![Select secret](_resources/free-text-decryption-2.png ':size=500x')

*Select secret to decrypt with*

## Step 3: Decrypt value

In this step, after selecting your secret, you can then obtain the decrypted value.

![Outcome](_resources/free-text-decryption-3.png)

*Decrypted value*
