Enrich and unlock your data with Synthetic Data Generation
What is synthetic data?
Synthetic data is generated using statistical models and generative AI techniques that learn patterns and relationships in real-world data. It is suitable for scenarios where statistical patterns in an existing dataset need to be retained, or if you require a more realistic dataset.
Empowering Government Innovation with Synthetic Data
Secure Data Sharing
Preserve privacy and meet stringent compliance standards with synthetic data. By replicating the statistical integrity of real data without exposing sensitive details, it provides a robust framework for secure testing and development within government projects.

Boost your productivity with Mock Data Generation
What is mock data?
Mock data is created using rule-based approaches, designed to mimic the structure and format of real-world data, with support for SG-specific entities. Unlike Synthetic Data Generation, Mock Data Generation does not learn from real-world data patterns. It is suitable for scenarios requiring predictable and repeatable datasets that do not have to be very realistic.

Enhance learning experiences and skills development. Mock data allows learners to practice basic data analysis and database management without compromising sensitive information.
Data Preview or Exploratory Data Analysis
Facilitate early-stage data exploration by generating representative mock datasets. This allows data scientists and analysts to develop and test hypotheses, design visualisations, and plan analytical approaches before accessing actual data.
Frequently Asked Questions
Who can use Mirage? Is it free?
Mirage is currently free for all approved users (no charge for FY26). It is available to Whole-of-Government (WOG) users, as well as select non-WOG users including public healthcare institutions and non-government data contributors on a case-by-case basis. WOG users can log in directly with WOG-AD or TechPass. For access issues, contact us at https://go.gov.sg/mirage-support.
Does Mirage store my data?
Mirage does not retain data. Raw data is purged upon completion of data generation. All data is encrypted in transit and at rest. Note: Mock data generation does not require any input data and therefore does not pose a data-transfer concern.
What data classification can Mirage handle?
Mirage supports Government data classified up to Confidential Cloud-Eligible (CCE), Sensitive-High (SH). This applies to synthetic data generation, which requires uploading real data for model training. The data owner remains responsible for use-case approval and residual-risk acceptance. Mock data generation does not require any input data and therefore does not pose a data classification concern.
Is the synthetic output automatically safe to share?
No. While synthetic data is generated from statistical patterns rather than copied directly, the data owner must assess the output for residual privacy risk using the privacy report. Classification and sharing approval must be reassessed based on the output and its intended use.
Is an API available?
Mock Data Generation is available via API through Cloak (https://cloak.gov.sg). Synthetic Data Generation is currently available through the Web UI only. If you have a use case requiring SDG API integration, please raise a support ticket at https://go.gov.sg/mirage-support.
