Getting Started
Login Today
For WOG users: Log in immediately at cloak.gov.sg using WOG-AD. No onboarding required for the Web UI. API access can be requested.
For Non-Government entities: Access is approved on a case by case basis for entities in service for public sector outcomes. Contact Cloak team at cloak@tech.gov.sg for inquire.
