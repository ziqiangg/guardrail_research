# Singapore Passport

---

### Singapore Passport Number

Detects Singapore passport numbers.

---

### Default setting:

- REPLACE all Singapore passport numbers with the `<SG_PASSPORT>` tag.

---

### Example:

| Original Value                                             | Anonymised Value                                    |
|------------------------------------------------------------|-----------------------------------------------------|
| My passport number is E1234567A.                           | My passport number is `<SG_PASSPORT>`.              |
| Please submit a copy of passport K9876543Z for verification. | Please submit a copy of passport `<SG_PASSPORT>` for verification. |
