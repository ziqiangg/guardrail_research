# Retention

Retention preserves values by leaving them unchanged.

---

## Examples

| Original value | Transformed value |
|----------------|-------------------|
| 355014         | 355014            |
| 716014         | 716014            |
| 240589         | 240589            |
| 624914         | 624914            |
