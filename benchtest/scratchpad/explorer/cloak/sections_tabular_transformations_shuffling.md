# Shuffling

Shuffling rearranges the values of a data field so that the values of individual data fields are still represented in the dataset but do not always correspond to the original records.

>Shuffling is also referred to as **swapping** and **permutation**.

Shuffling can be helpful when the analysis is required on the aggregated data or analysis is at the intra-data field level; meaning, there is no need for analysis of relationships between data fields at the record level.

---

## Examples

| Original column values | Transformed column values |
|-----------------------|---------------------------|
| Robert                | Samantha                  |
| Samantha              | Harvey                    |
| Harvey                | Katrina                   |
| Katrina               | Robert                    |
