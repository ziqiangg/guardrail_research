Header prefix is an open CP1 choice (R004): the headers below use one prefix `Purple Llama:` with the component in a parenthesis (fits one registry entry and the `HDR_RE` rule; per-tool prefixes are the alternative, Q11). IDs use prefix PL (drafts/README.md).

|---|---|---|---|---|
| PL1 | `Purple Llama: Prompt-attack detection (Prompt Guard 2 model)` | Standalone mDeBERTa/DeBERTa classifier that labels a string benign or malicious (jailbreak and injection). | Undifferentiated string classifier: one column, R3/R6 say prompts, retrieved text and tool output alike | E01 to E06 |
