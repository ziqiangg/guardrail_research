## 2. Function list (proposed Table 3 columns)
Prefix proposed: `Sensitive Data Protection:` (the name Google's docs and pricing page use; "Google Cloud" omitted as the vendor prefix is not part of the product name in its own docs; "Cloud DLP" is the legacy name). See Q01.

R002 handling: every content method takes one `ContentItem` (string, table, bytes, conversation or batch) and has no input/output flag. `Conversation.messages[].participantId` is a free-text identifier and `messageType` is CONTENT or CONTEXT, which is not a prompt/response flag (E12). So per the R002 definition (string-only surface) each function is a single undifferentiated column; R3 and R6 must say it applies to prompts, responses, retrieved text and tool output alike. The one exception to watch is SD7 (content policy), which is wired by Gemini Enterprise connectors and uploads (E20, E21), not by prompt or response direction.
