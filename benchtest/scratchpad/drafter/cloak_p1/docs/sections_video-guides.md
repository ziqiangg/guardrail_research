# Video Guides

## Workshop Recordings

### Feb 2025 Workshops

These workshops were conducted for Cloak's February 2025 release, and covers:

- Introduction to Cloak and common use cases
- Adding structured custom entities using pattern matching
- Adding unstructured custom entities using LLMs
- Sharing of Secrets and Salts
- API access
- Templates
