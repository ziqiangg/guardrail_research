# Anonymisation Techniques

The following anonymisation techniques are currently available. These will be regularly updated to align with IM Guidelines and Cloak (Tabular)'s custom features. 

- [Pseudonymisation](/sections/fta/anonymisation-techniques/pseudonymisation.md) (Hashing)
- [Masking](/sections/fta/anonymisation-techniques/masking/intro.md)
    - [NRIC Masking](/sections/fta/anonymisation-techniques/masking/nric-masking.md)
- [Redact](/sections/fta/anonymisation-techniques/redact.md)
- [Replace](/sections/fta/anonymisation-techniques/replace.md)
    - Replacement of the word based on the Entity Type
- [Encrypt](sections/fta/anonymisation-techniques/encrypt.md)
    - Based on a key provided, encrypt the words
