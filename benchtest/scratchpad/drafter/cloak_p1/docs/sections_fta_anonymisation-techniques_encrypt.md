# Encrypt

Using a key, encrypt the following words

[Microsoft Presidio](https://microsoft.github.io/presidio/tutorial/12_encryption/) has a built-in encryption functionality, to encrypt and decrypt identified entities. The encryption uses [AES cypher in CBC mode][#] and requires a cryptographic key as an input for both encryption and decryption. **AES-256 Encryption is recommended**. The output would be in base64. 

>Due to security reasons, we have restricted encryption to only AES-256 CBC Mode Encryption.

---

### Example:

| Original value      | Transformed value        | Secret Key              |
|---------------------|--------------------------|-------------------------|
| Jason               | pX09dIQ4X3gU1FC3r8pZXA== | **nZr4u7x!z%C*F-JaNdRgUkXp2s5v8y/B**|
