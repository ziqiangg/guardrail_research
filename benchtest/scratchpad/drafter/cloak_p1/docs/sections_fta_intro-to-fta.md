# Free Text Anonymisation  
**User Guide for Cloak's Free Text Anon Tool**

## Overview  
Cloak's Free Text Anon tool aims to help users share and analyse unstructured data in a secure and privacy-preserving way. It automatically detects and redacts/transforms sensitive information within unstructured text, enabling secure data sharing and collaboration while preserving data utility.

FTA can be applied for the following use cases:  
- Employee feedback  
- Emails from the public  
- Resume analysis  
- Procurement documents  
- Investigation reports  

The tool supports pasted text input as well as file uploads (.csv, .pdf, .docx). See the [Usage Guide](/sections/fta/usage-guide.md) for details on supported formats and limitations.

![Free-Text Anonymisation overview](_resources/intro-fta-overview.png)
*Cloak detects and transforms 20+ baseline entity types (names, NRICs, addresses, dates, phone numbers, etc.) as well as custom entities defined via pattern matching, inclusion lists, or privately-hosted LLMs.*
