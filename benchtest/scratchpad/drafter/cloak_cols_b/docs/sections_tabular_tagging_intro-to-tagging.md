# Data Tagging

Data tagging enables you to identify sensitive data and determine the best ways to protect it. Cloak supports the tagging of data fields in accordance with [information](/sections/tabular/tagging/information-types.md) and [sensitivity](/sections/tabular/tagging/sensitivity-types.md) types for this purpose.

For the [info type](/sections/tabular/tagging/information-types.md) tagging, Cloak offers a pre-defined collection of information types (e.g., NRIC, ZIP code). We plan to add more information types in the future to support a variety of use cases. Automated data field detection will be done for fields which fall in the pre-defined collection.

![data-tagging-1](_resources/data-tagging-1.png ':size=300x')

*The information type dropdown showing pre-defined categories such as NRIC, Name, Email, and Zipcode.*

For [sensitivity type](/sections/tabular/tagging/sensitivity-types.md) tagging, Cloak allows the categorisation of data fields into commonly used sensitivity types — <b>Direct Identifiers, Indirect Identifiers, Sensitive, and Non-Sensitive</b>. The sensitivity types are based on potential identity and attribute disclosure risks for each data field. 

![data-tagging-2](_resources/data-tagging-2.png ':size=500x')

*The sensitivity type dropdown showing the four categories: Direct Identifier, Sensitive, Indirect Identifier, and Non-Sensitive.*
