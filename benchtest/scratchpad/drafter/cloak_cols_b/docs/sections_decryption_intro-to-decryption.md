# Secret Sharing and Decryption

Cloak provides a secure way to store, manage, and share the encryption keys and salts used in your anonymisation jobs. This replaces insecure practices like storing keys in spreadsheets or emailing them between colleagues.

**Why this matters:**

- **Consistent anonymisation across datasets** - Use the same keys or salts to encrypt or pseudonymise entities consistently, enabling dataset linkage on primary keys without exposing the originals.
- **Secure sharing and continuity** - Share secrets with colleagues without exposing the underlying key material, and ensure access persists across role changes and departures.

**Getting started:**

- [Tabular Decryption Guide](/sections/decryption/tabular-decryption.md) - Decrypt tabular datasets using a shared secret
- [Free-text Decryption Guide](/sections/decryption/free-text-decryption.md) - Decrypt individual encrypted values
