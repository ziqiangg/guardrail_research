# Tabular Data Anonymisation

Tabular Data Anonymisation allows users to [tag](/sections/tabular/tagging/intro-to-tagging.md) and transform data through [transformation/anonymisation techniques](/sections/tabular/transformations/intro-to-transformations.md) and address [re-identification risk](/sections/tabular/privacy-risk-score/k-anonymity-test.md) through [k-anonymity](/sections/tabular/privacy-risk-score/k-anonymity-test.md) checks. 

The graphical frontend of Cloak provides an intuitive interface and provides various **visualisations**, and **context-sensitive help**.
