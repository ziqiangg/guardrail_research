# Name
*Name refers to a person's Name (First, Last or Full Name), including ethnic names in roman characters.*

**Default setting:**

- REPLACE names with `<PERSON>` tag.

---

### Example:

| Original Value                  | Anonymised Value               |
|--------------------------------|--------------------------------|
| Jason Chew is a man.           | `<PERSON>` is a man.           |
| She is Amber, the woman.       | She is `<PERSON>`, the woman.  |
