# Credit Card

---

### Default setting:

- REPLACE credit card numbers with a `<CREDIT_CARD>` tag.

---

### Example:

| Original Value                               | Anonymised Value                |
|----------------------------------------------|-------------------------------|
| Is this my card number: 5123-1234-1234-7621? | Is this my card number: `<CREDIT_CARD>`? |
| Would the number on my card be 5215604694467621? | Would the number on my card be `<CREDIT_CARD>`? |
