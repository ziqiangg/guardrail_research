# Nationality/Race/Religion/Political Group (NRP)

Nationality, Race/Religion and Political Group can be detected.

NRP detects values that correspond to a Nationality (e.g. Singaporean), Race (e.g. Chinese), Religion (e.g. Christian) and political groups.

---

### Default setting:

- REPLACE all NRP values with `<NRP>` tag.

---

### Example:

| Original Value                                             | Anonymised Value                                    |
|------------------------------------------------------------|----------------------------------------------------|
| Jason is a Singaporean Chinese who happens to be a Christian. | Jason is a `<NRP>` `<NRP>` who happens to be a `<NRP>`. |
| Amber is from India and happens to be Indian.              | Amber is from India and happens to be `<NRP>`.     |
