# Email Address

**Default setting:** 

- REPLACE email addresses with `<EMAIL_ADDRESS>` tag.

---

### Example:

| Original Value                                  | Anonymised Value                      |
|------------------------------------------------|-------------------------------------|
| You can email Jason at jason@gmail.com.         | You can email Jason at `<EMAIL_ADDRESS>`.     |
| Amber Heard can be contacted using this, amber@government.com. | Amber Heard can be contacted using this, `<EMAIL_ADDRESS>`. |
