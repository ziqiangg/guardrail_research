# Transposition

Transposition shifts each alphanumeric character down by a fixed number of steps. This is a reversible encryption technique.

>This is a reversible, simple, and one of the most widely used encryption techniques known as [Caesar cipher]($).

---

## Examples

| Original value | Transformed value |
|----------------|-------------------|
| T0581222F      | W3824555I         |
| F0005772O      | I3338115R         |
| T7303748A      | W1636172D         |
| T6353952U      | W0686385X         |
| S6505606X      | V0838030A         |

---

## Usage Guide

| Inputs          | Description                                   | Default |
|-----------------|-----------------------------------------------|---------|
| Number of steps | Used to set the number of characters to shift | 1       |
