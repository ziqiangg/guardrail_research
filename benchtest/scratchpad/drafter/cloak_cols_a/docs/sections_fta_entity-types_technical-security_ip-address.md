# IP Address

### Internet Protocol (IP) address (either IPv4 or IPv6)

---

### Default setting:

- REPLACE IPv4 or IPv6 IP addresses with a `<IP_ADDRESS>` tag.

>Currently, the FTA tool does not support CIDR Block notation.

---

### Example:

| Original Value                                               | Anonymised Value                            |
|--------------------------------------------------------------|--------------------------------------------|
| Please do not hack me, but my standard IPv4 address is 192.158.1.38. | Please do not hack me, but my standard IPv4 address is `<IP_ADDRESS>`. |
| I am planning to upgrade it to an IPv6, and it will ultimately look like this:  2001:db8:85a3:8d3:1319:8a2e:370:7348. | I am planning to upgrade it to an IPv6, and it will ultimately look like this: `<IP_ADDRESS>`. |
