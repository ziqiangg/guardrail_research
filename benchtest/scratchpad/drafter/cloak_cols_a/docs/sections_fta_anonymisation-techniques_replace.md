# Replace

Replace identified token with a word or tag of your choice

Replaces the identified original value with the replaced value that you entered. By default, it would be <**ENTITY_NAME**>.

---

### Example:

| Original value      | Transformed value      | Comment                 |
|---------------------|------------------------|-------------------------|
| Jason               | <PERSON>               | <**PERSON**> - "Jason" is identified as a PERSON Entity, so the value has been replaced. |
