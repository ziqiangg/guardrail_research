The Central Privacy-Preserving Toolkit
Cloak is a WOG data anonymisation toolkit that enables agency users and system implementors to transform and anonymise data for secure and IM-compliant data utilisation — for policy analysis, operations, and Gen AI applications. Available as a Web UI for public officers, and as API integrations for platforms, pipelines, and workflows.

Frequently Asked Questions
What privacy features does Cloak offer?
Cloak provides:
Tabular data anonymisation — transform structured datasets using masking, hashing, pseudonymisation, generalisation, perturbation, suppression, and k-anonymity assessment
Free text anonymisation — automatically detect and redact PII from unstructured text, optimised for Singaporean data with support for LLM-powered custom entities
Secrets and salts management — securely store, share, and audit encryption keys across teams
What kind of data can I use with Cloak?
Cloak supports Government data classified up to Confidential Cloud-Eligible (CCE) and Sensitive-High (SH).
Supported file formats:
Tabular: CSV
Free text: CSV, DOCX, PDF
Does Cloak store my data?
Cloak does not retain data. Raw data is purged upon anonymisation and anonymised data is purged within 24 hours or upon user request. All data is encrypted in transit and at rest.
Ways to access Cloak
Cloak is available through multiple access modalities:
Web UI — No-code, point-and-click web app with k-anonymity and WOG Mode A/B recommendations
APIs — Intranet (from Analytics.gov or GCC) and Secure Internet API for system-to-system integration
Who can use Cloak? Is it free?
Cloak is currently free for all public sector users and approved non-public sector users. It is also available to Non-Government Entities (NGEs) on a case-by-case basis.
