Cloak
Overview
Cloak
PROOF OF VALUE
Cloak provides free-text and tabular data anonymisation so agencies can safely share, analyse, or send sensitive data to AI products. It is approved to handle data up to Confidential Cloud-Eligible, Sensitive-High, and is optimised for Singaporean PIIs with >97% recall like Names, NRICs, and Emails. Access via the Cloak Web UI or integrate through the API. Open to WOG users and select non-government entities including public healthcare.
View Features Sign in
Key Benefits
Safe for Sensitive Data
Able to handle up to Confidential Cloud-Eligible, Sensitive-High data. No data retention
Automated Policy Compliance
Designed to enable IM8 compliance with guided access-mode selection and k-anonymity testing against WOG Modes A and B.
Highly Customisable
Add any custom entity using inclusion lists, pattern-matching (regex), or privately-hosted LLMs to improve detection for your specific dataset.
Scalable
Integrate via API into platforms, pipelines, and workflows. Currently processing >5 million PIIs removed per month across WOG.
Collaborative
Share encryption secrets across data owners so anonymisation can occur independently but data can still be fused using a common encrypted identifier.
