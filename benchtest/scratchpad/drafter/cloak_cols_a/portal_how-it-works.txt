How It Works
Cloak is a web application designed for public service officers to upload, tag, and transform data while managing re-identification risks. It also offers API access. Below is a step-by-step guide for using Cloak to anonymise tabular datasets. For free-text anonymisation, there is no need for manual data tagging, as Cloak automatically identifies entities within the text.
