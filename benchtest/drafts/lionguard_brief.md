## Scope (user-decided unless marked CP1 DEFAULT)
- **LionGuard** is GovTech Singapore's localised content-moderation classifier. Per R005 this product covers **the open models you run yourselves**, from the Hugging Face org `govtech`: LionGuard 2, LionGuard 2.1 and LionGuard 2 Lite. LionGuard 1 (`govtech/lionguard-v1`) is legacy: inventory only, never a Table 3 column (R007 item 3).
- **What the models are.** Only the small classifier head is GovTech's weight (3.4 MB for 2 and 2.1, 1.0 MB for Lite). Each variant needs a separate embedding model: OpenAI `text-embedding-3-large` (2, hosted API, your own key), Gemini `gemini-embedding-001` (2.1, hosted API, your own key) or Google `embeddinggemma-300m` (Lite, runs locally, Hugging Face gated behind Google's Gemma terms). R7 and inventory (c) must say so plainly (Q03 default).
- **It is a classifier, not a guardrail with a verdict.** The model returns probabilities per output key. No threshold ships with it. R5 and R7 must say so.
- **Direction (R002).** The model takes an embedding of one string. There is no input/output flag, endpoint or config section. So the function is **one undifferentiated column**, with no `Input-level` or `Output-level` prefix (the Sentinel AA precedent). R3 and R6 must say the column applies to prompts and responses, and to retrieved text, tool inputs and outputs on the data path (the last is `[Inferred]` from "one string in"). GovTech's own blog headings call LionGuard 2 an input and output guardrail; cite that as a documented use, not as a flag.
- **Cross-reference, do not duplicate (R005).** Sentinel is GovTech's hosted API, which serves the same three variants under the ids `lionguard-2`, `lionguard-2-1` and `lionguard-2-lite`. Hosted-API behaviour (endpoints, `x-api-key`, request and response shape, the `lionguard-2-*` guardrail ids, per-version token limits, which variant a suite key runs, rate limits, closed-beta access) **stays under Sentinel column AA (`SN1`) and sheet 3e**. In LionGuard columns, give at most one cross-reference bullet per row where it helps (R4 and R8 mainly), citing the Sentinel source with "(Sentinel docs, hosted API)". Reuse the Sentinel finals' verified facts only after re-checking them at source (R005).
- **Out of scope for this product:**
  - Sentinel's other guardrails (prompt-attack, off-topic, system-prompt-leakage, refusal, AWS wrappers) and the off-topic HF models: Sentinel and sheet 3e.
  - GovTech Cloak and Litmus: separate products.
  - Third-party embedders' own behaviour (OpenAI, Google): only what GovTech's pages say, plus the owners' gating, licence and terms pages for inventory (c) per R019, marked "not GovTech docs".
- **Honesty rule.** The vendor publishes no operating threshold for 2, 2.1 or Lite, no Lite evaluation, no latency for 2.1 or Lite, and no training code. Re-check, then write `[Not disclosed]` and name what you checked. Never use a model's training notebook or demo as a vendor recommendation unless it says so.
