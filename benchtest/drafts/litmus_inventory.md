# Litmus inventory (draft, sheet 3x)

Scope: GovTech Litmus, the hosted multi-tenant Testing-as-a-Service platform that is part of AI Guardian. Litmus sends curated prompts to a tenant's AI application and scores the responses; it is an evaluation tool, so it has no Table 3 columns (R003) and every Covered by cell carries the inventory-only marker (R011). The 14 individual tests, the published-results rows and the engine and judge questions are on the Litmus evaluation-tooling sheet, not here. This sheet lists only how Litmus is reached (a), which suites and identifiers are named (b) and which integration parameters are published (c). Litmus is a hosted service: no release, tag or version number is published (checked the AI Guardian docs pages, the developer portal pages and the playbook page) [Not disclosed]. Nothing was signed in to, submitted or called (R019): the web app, the API and the interest form were not opened, and the hosts below are read from page text and link targets only. Pages were read 2026-10-10 with fetch_text.py.

Short names (defined once): AIG = https://www.aiguardian.gov.sg/docs/wiki/ pages Litmus-Overview, Litmus-Getting-Started, Litmus-Troubleshooting and Test-Information-Documentation (the AI Guardian Docusaurus site, no source repository found, unpinned) [Documented]; DEV = https://www.developer.tech.gov.sg/products/categories/cybersecurity/litmus/ pages overview, features-roadmap, how-it-works, getting-started and resources (GovTech developer portal; page dates Overview 19 May 2025, How it works 13 May 2025, Features and Roadmap 06 May 2025, Resources 13 May 2025, Getting Started 06 May 2025) [Documented]; PB = playbook files in govtech-responsibleai/playbook at commit 45908b48 (full SHA 45908b48c0a8b6d3855a154c0e41a12958a99205, the staging branch commit that matches the deployed page text "Last updated on Sep 14, 2026", as for Sentinel R007 item 7) [Documented: repo govtech-responsibleai/playbook@45908b48]; ACT = action.yml in dsaidgovsg/aiguardian-test-action at tag v0.0.1 (commit 190600937062c100d0c10181e3edf71702230244, the only file; no README) [Documented: repo dsaidgovsg/aiguardian-test-action@v0.0.1].
