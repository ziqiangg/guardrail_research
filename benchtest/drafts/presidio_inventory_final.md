The ANON built-in operators table lists replace, redact, hash, mask, encrypt, custom, surrogate_ahds and keep as Anonymize and decrypt as Deanonymize [Documented] (ANON), and does not list deanonymize_keep; the code is preferred for what exists. When the operators map is empty or has no DEFAULT key the operator is replace for all entities [Documented] (ANON: "the default anonymization operator is "replace" for all entities"). Overlaps: the higher score wins, a contained entity yields to the larger one, and partial overlaps are each anonymised [Documented] (ANON).
