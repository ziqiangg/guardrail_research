## Verified OK (passed as written)

Tools
- Moderation, fact-checking and hallucination bypass the rail pipeline: `evaluate_moderation.py` calls `llm_call(prompt=..., llm=self.llm)` with `render_task_prompt(Task.SELF_CHECK_INPUT/OUTPUT)`; `evaluate_factcheck.py` does the same with `SELF_CHECK_FACTS`; `evaluate_hallucination.py` calls `self.llm(...)` with `SELF_CHECK_HALLUCINATION`. `LLMRails` is built only to get `.llm` (load-bearing claim confirmed).
- Scoring is substring matching (moderation `"yes" in`, `label in`; fact-check `label in`; hallucination `"no" in`), with the code's own admissions ("cannot judge output moderations accurately"; "cannot catch predictions that are not hallucinations").
- Moderation: 3 retries on the input rail only; output reply temp 0.1, max 100 tokens; defaults 50 samples, `eval_outputs/moderation`, split label from the name.
- Fact-check: negatives by LLM at temp 0.8; positive, negative and overall accuracy; ms per fact; AlignScore not exercised by code.
- Hallucination: 2 extra samples at temp 1.0, base answer at temp 0.2, max 100 tokens.
- Topical: builds `LLMRails`, uses `rails_app.runtime.generate_events`, exact intent match plus optional `all-MiniLM-L6-v2`, defaults 0.3 / 3 / 0 / 10 / 0.0.
- `eval run`: `LLMRails.generate_async` with `prompt=` or `messages=`; results saved after each interaction; reuse on re-run; `-g` required.
- `eval check-compliance` needs an LLM judge: `--llm-judge` has no default and the checker exits if the model is not in the eval config; temp 0; `Reason:`/`Compliance:` regex; invalid replies ignored; SQLite cache; the unformatted f-string bug is real (`self.progress.print("[{progress_idx}] ...")`).
- `compute_compliance` rate = comply / (comply + violation + not rated); n/a excluded.
- Expected-output types `generic`, `refusal`, `similar_message`; policy fields `id`, `description`, `weight`, `apply_to_all`; interaction-set fields.
- Methodology page: precision, recall, F1 "you need to compute these with other tools".
- garak generators: `NeMoGuardrails` loads `RailsConfig.from_path(name)`, builds `LLMRails`, calls `generate(messages=...)`, `supports_multiple_generations = False`; `NeMoGuardrailsServer` default URI `http://localhost:8000/v1/` with `config_ids`.
