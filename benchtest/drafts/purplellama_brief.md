- **PL5 Regex scanner and custom scanners.** `RegexScanner` (fixed default patterns: prompt-injection phrases, email, phone, credit card, social security number; `BLOCK` on first match, score 1.0; `block_threshold` 1.0; no constructor argument for other patterns, P1 check) plus the extension route: subclass `Scanner`, register with `register_llamafirewall_scanner` (code), versus the docs' stale `BaseScanner` instructions; and, as a Detail sub-topic inside this column by default, the experimental LLM-prompt scanners `CustomCheckScanner` and `PIICheckScanner` (default Llama 3.3 70B via Together, threshold 0.7). - **PL6 Code Shield (engine).** The standalone `CodeShield` class (`CodeShield.scan_code`) and the ICD library: regex and Semgrep analyzers, `Treatment` (block, warn, ignore), `CodeShieldScanResult`, language support (see the conflict table), rule layout, CWE coverage, the two-layer scan, latency statements, MIT licence, `semgrep` dependency. Not LlamaFirewall wiring (PL4).
- **PL7 Hidden ASCII scanner (provisional).** `HiddenASCIIScanner`: blocks any text containing a Unicode tag character U+E0000 to U+E007F and decodes it into the reason; threshold 1.0; no model, no external key.
