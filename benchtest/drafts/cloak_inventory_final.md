# Cloak inventory (final, sheet 3x)

Scope: GovTech Cloak ("The Central Privacy-Preserving Toolkit", formerly enCRYPT), a closed hosted data-anonymisation service for Singapore Government users and selected non-government entities. It transforms personal data in text, documents and tables (replace, redact, mask, alias, hash, encrypt); it returns transformed text or files, the Web UI findings table lists a confidence score per detected entity, and no safe or unsafe verdict is described. The sources are the Cloak Guide Markdown pages, the Cloak product site, the Developer Portal Cloak pages, the Terms of Use and Privacy Statement PDFs, and mirage.gov.sg, all read 2026-10-10 (HTTP 200 unless stated). There is no public repository, Hugging Face entry or package for Cloak, so no code pin applies; Cloak Guide pages are cited as [Documented] without a pin. The API Guide, API Specifications and package guide return a login redirect (HTTP 302 then a 200 login page, observed 2026-10-10), so their content is [Not disclosed]. Block (f) uses owners' pages, marked "not GovTech docs", and pinned repo labels only for those owners. Labels use the sheet's allowed forms; typographic quotes in the Terms PDF are normalised to ASCII. Short names (page names under https://docs.developer.tech.gov.sg/docs/cloak-guide/sections/): HOME = home.md; FAQ = faqs.md; FTAI = fta/intro-to-fta.md; USE = fta/usage-guide.md; ENTI = fta/entity-types/intro.md; NAME, NRIC, EMAIL, PHONE, NRPG, ADDR, LOCN, PASS, CURR, CARD, SGBK, IBAN, IPAD, URLE, DATE, UENP, ORGN, EXCP, CUST = the entity pages under fta/entity-types/; FIXD, STRC, LLMI, ADDE, PRMP = custom-entities pages (fixed list, structured, unstructured intro, how to add, how to write prompts); CONF, INCL = advanced-features pages (confidence level, inclusion feature); ALIAS, ENCR, PSEU, REDA, REPL, RUNQ, MASK, NRMK = anonymisation-techniques pages (alias, encrypt, pseudonymisation, redact, replace, replace-unique, masking intro, NRIC masking); SECR, FTDC, TABD, DECI = decryption pages (secrets manager, free-text decryption, tabular decryption, intro); TPL = templates/templates.md; APIG = developer-api-guide.md; PKG = packages-anonymiser.md; REGG = registration-guide.md; REL = release-notes.md; CRED = credits.md; VIDG = video-guides.md; TABI, TABU = tabular intro and usage guide; SIDE = the _sidebar.md list of 80 paths.
