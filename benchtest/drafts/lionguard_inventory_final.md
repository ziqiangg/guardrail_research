# LionGuard inventory (final, sheet 3x)

Scope: GovTech LionGuard, the localised content-moderation classifier published as open models on the Hugging Face org govtech: LionGuard 2, LionGuard 2.1 and LionGuard 2 Lite (covered by the single Table 3 column LionGuard: Localised harmful-content classification), plus LionGuard 1 as legacy (inventory only). Each variant is only a small classifier head; it needs a separate embedding model that GovTech does not ship (OpenAI for 2, Gemini for 2.1, Google EmbeddingGemma for Lite). The hosted Sentinel API that serves the same three variants stays under Sentinel column AA and sheet 3e; this sheet cross-references it and does not repeat it. Labels use the sheet's allowed forms. HF repo facts are pinned to the revision sha8 shown in each label (full shas are in the Source URL cells); playbook facts are pinned to govtech-responsibleai/playbook at 45908b48 (the branch the playbook site is built from; the same page text is on main at 97338569; page footer reads Last updated on Jul 28, 2026); source hints are plain text after the label. Third-party pages (OpenAI, Google, BAAI, Hugging Face pages of other owners) are cited only for embedder identity (model name, input limit, output dimension), gating, licence and terms, and are marked "not GovTech docs". Short names: G = aiguardian.gov.sg Sentinel-Guardrails docs page (cross-reference only); GS = Sentinel Getting Started page; PB = playbook LionGuard page; PBS = playbook Sentinel page; P2 = arXiv 2507.15339 (LionGuard 2, html v2); P1 = arXiv 2407.10995 (LionGuard 1); RB = arXiv 2507.05980 (GovTech RabakBench paper, html v2 of 2 Feb 2026); B1 = blog.ai.gov.sg post of 29 Jul 2025; B2 = post of 21 Aug 2026; B3 = post of 28 Sep 2026; HFAPI = Hugging Face Hub API; OAI = OpenAI developer docs; GEM = Google Gemini API docs; EG = Hugging Face page of google/embeddinggemma-300m. All pages and files were read on 2026-10-09 as raw text; nothing was installed, run or downloaded, and no model or embedding service was called; the public Hugging Face Hub metadata was read with plain GET requests.
