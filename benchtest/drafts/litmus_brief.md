## Scope (user-decided unless marked CP1)
- **GovTech Litmus** (part of AI Guardian) is a hosted, multi-tenant Testing-as-a-Service platform that sends curated prompts to a tenant's generative AI application and scores the responses before deployment. It is an evaluation tool, so it gets an **evaluation-tooling sheet only and no Table 3 columns** (R003; "Litmus has no Table 3 columns at all"). There is no `_cols_a.md`, no `_two_level.md` and no column ID prefix (drafts/README.md "Headers and IDs": litmus is "eval sheet only").
- **Direction note (R002).** Litmus is not an inline guardrail. It sends prompts to a tenant endpoint and judges the application's responses. Say this once in the Overview and do not label any Litmus function "Input-level" or "Output-level".

- **Inventory sheet: CP1 question Q-A below** (default and alternative recorded; do not decide).
- **Out of scope.** Sentinel (done, sheet 3e; cross-reference in plain text only). ## The three pages that return 403 (main's q03 ruling; P1 result)

- `https://www.aiguardian.gov.sg/docs/wiki/Litmus-Onboarding-Guide`
